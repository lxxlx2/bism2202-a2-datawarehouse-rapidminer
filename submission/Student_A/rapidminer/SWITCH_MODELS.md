# Inspecting one model

The main process runs both model branches. To inspect one candidate independently, open its `holdout_*.rmp` companion. For the training-only workflow, open its `cv_only_*.rmp` companion. Double-click Cross-Validation to inspect the training and testing subprocesses. Return to the root process with the process breadcrumb. The same learner settings are used throughout.

If practising the model-switching method described in the assignment, use a copy of the process, reconnect the relevant branch and disable operators that will not run. Keep the final submitted process and its experiment parameters unchanged.
